# Homebrew maestro-runner

Homebrew tap for [maestro-runner](https://github.com/devicelab-dev/maestro-runner), with native support for Apple Silicon and Intel Macs.

## Install

After publishing the tap, install on any Mac with:

```bash
brew install --cask turbogerald/homebrew-maestro-runner/maestro-runner
```

Verify the installation:

```bash
maestro-runner --version
```
